# Builds locais

Esta pasta contém somente artefatos gerados para teste, separados por plataforma:

- `Windows/`: instalador NSIS e versão portátil `.exe`.
- `Android/`: APK de teste.

Os diretórios de código-fonte continuam em `Windows/` e `Android/`. Os scripts sempre sobrescrevem apenas a saída da plataforma correspondente.
