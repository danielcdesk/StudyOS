# 📦 Histórico de releases

## v1.0.0 — Public beta

Primeiro pacote público para testes do StudyOS.

### Incluído

- 🪟 Instalador Windows 11 (NSIS).
- 🪟 Executável portátil para Windows 11.
- 📱 APK experimental para Android.
- 🌐 Interface web atualizada com dashboard, questões, foco, provas, redações, guia de estudos e configurações de tema.
- 🔒 Armazenamento local e exportação/importação de backup JSON.
- 🧠 Projeto desenvolvido com apoio de inteligência artificial (IA), sempre com revisão humana e testes.

### Notas importantes

- O app não depende de iniciar um `batch` ou servidor Python para o uso distribuído.
- A interface web pode ser atualizada sem reinstalar o invólucro nativo.
- Mudanças no invólucro Windows/Android exigem um novo artefato.
- O APK é experimental; teste em um aparelho secundário e mantenha um backup dos estudos.
- Nenhum dado pessoal de usuário deve ser anexado a uma issue, release ou commit.
