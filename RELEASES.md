# Releases do StudyOS

## v1.0.0 — Public beta

Versão de teste pública do StudyOS, publicada com apoio de inteligência artificial (IA), revisão humana e testes locais.

### Incluído

- 🪟 Aplicativo Windows em formato instalador e portátil.
- 📱 Projeto Android com Capacitor, ícone próprio e pipeline de APK.
- 💾 SQLite local com preservação dos dados do usuário durante atualizações.
- 🎨 Temas, onboarding personalizável e interface otimizada para uso leve.
- 🧪 Auditoria automatizada da interface e verificação de sintaxe.

### Artefatos

Os arquivos de teste ficam anexados na página de [Releases](https://github.com/danielcdesk/StudyOS/releases). O APK permanece experimental enquanto o ambiente de build Android não estiver disponível com JDK 17+.

> Faça backup dos seus estudos antes de trocar de dispositivo. Este projeto não deve ser usado como única fonte para decisões acadêmicas importantes.
